# iDevs Development Stack

## Frontend (Novo)
- **Framework**: Vite + React + TypeScript
- **Styling**: Vanilla CSS (Premium Aesthetics, Dark Mode por padrão)
- **State Management**: React Context / Hooks
- **HTTP Client**: Axios
- **Icons**: Lucide React
- **Scanning**: Html5-qrcode (Para leitura de Chromebooks via QR)
- **Routing**: React Router DOM

## Backend (Existente)
- **Framework**: FastAPI
- **Language**: Python 3.12+
- **Database**: PostgreSQL (SQLAlchemy + Alembic)
- **Auth**: OAuth2 JWT (Implementado em `configs/security.py`)
- **Server**: Uvicorn

## Infraestrutura
- **Containerização**: Docker & Docker Compose
- **Documentação**: OpenSpec (Governança iDevs)
